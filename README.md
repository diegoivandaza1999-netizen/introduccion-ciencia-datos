# introduccion-ciencia-datos

Actividad 2 - Introducción a la Ciencia de datos



Trabajo práctico de Git y GitHub



Este repositorio se desarrolla como parte de una actividad académica orientada al aprendizaje y la aplicación de Git y GitHub. Su propósito es comprender los conceptos fundamentales del control de versiones, la administración de archivos y el trabajo con repositorios locales y remotos.



Objetivo general

Aprender a utilizar Git y GitHub para organizar, documentar y controlar los cambios realizados en los archivos de un proyecto, mediante el uso de comandos básicos y la creación de un repositorio.



Contenido del repositorio

En este repositorio se organizarán los siguientes materiales:



Tutoriales de Pro Git: documentos de estudio correspondientes a los capítulos asignados.

Apéndices: material complementario sobre los entornos de trabajo, la integración de Git en aplicaciones y los comandos disponibles.



Archivos de práctica: documentos de texto utilizados para realizar ejercicios y registrar cambios.

README.md: archivo de presentación y descripción general del proyecto.

Informe de proceso: documento que describirá las actividades realizadas, las dificultades encontradas, las soluciones aplicadas y las conclusiones del trabajo.

Herramientas utilizadas

Git, para llevar el control de versiones de los archivos.

GitHub, para alojar el repositorio remoto.

Terminal de Windows, para ejecutar comandos de Git.

Microsoft Word y PDF, para elaborar y presentar los documentos académicos.



Procedimiento de trabajo

Durante el desarrollo de la actividad se utilizaron comandos como git add, git commit y git push, con el fin de preparar los archivos, registrar los cambios y enviarlos al repositorio remoto. También se documentará el proceso mediante capturas de pantalla y se elaborará un informe final.
